## 🤖 AI Agent Workflows

### Workflow 1: Implement a New Agent
1. Read [Agent Architecture](technical/AGENTS.md#agent-architecture)
2. Review [Base Agent Interface](technical/AGENTS.md#base-agent-interface)
3. Check similar agents in [Core Agents](technical/AGENTS.md#core-agents)
4. Define tools in [Skills](technical/SKILLS.md)
5. Follow [Standards](development/STANDARDS.md#architecture-patterns)

### Workflow 2: Create Agent Skill
1. Read [Skill Architecture](technical/SKILLS.md#skill-architecture)
2. Review similar skills in appropriate category
3. Define input/output schemas
4. Implement tool integration
5. Add to [Skill Registry](technical/SKILLS.md#skill-composition)

### Workflow 3: Integrate External System
1. Read [Integration Architecture](development/INTEGRATION.md#integration-architecture)
2. Check existing integration patterns
3. Implement authentication
4. Set up webhooks
5. Follow [Security Standards](development/INTEGRATION.md#security-considerations)

### Workflow 4: Write Production Code
1. Check [Code Style](development/STANDARDS.md#code-style-and-formatting)
2. Follow [Architecture Patterns](development/STANDARDS.md#architecture-patterns)
3. Implement [API Standards](development/STANDARDS.md#api-design-standards)
4. Add [Error Handling](development/STANDARDS.md#error-handling)
5. Write [Tests](quality/EVALUATION.md#automated-evaluation)

## 🚀 Performance Tips for AI Agents

### Efficient Document Loading
1. **Start here** → Use this INDEX.md to find the right document
2. **Load specific sections** → Use deep links to jump to sections
3. **Load only what you need** → Don't load entire documents if only one section is needed
4. **Use related links** → Each document has "Related Documents" section at the bottom

### Context Optimization
- **For agent implementation**: Load only [AGENTS.md](technical/AGENTS.md) and relevant agent section
- **For skill creation**: Load only [SKILLS.md](technical/SKILLS.md) and relevant skill category
- **For integration**: Load only [INTEGRATION.md](development/INTEGRATION.md) and specific integration section
- **For code standards**: Load only [STANDARDS.md](development/STANDARDS.md) and relevant section

### Memory Management
- **Unload unused documents** after completing task
- **Cache frequently accessed sections** (like base agent interface)
- **Use this INDEX** as your primary navigation tool
- **Load documents on-demand** rather than all at once
